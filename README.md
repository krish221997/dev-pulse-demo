# Dev Pulse Demo

A demo repository for showcasing Dev Pulse — an engineering command center built with One.

## What is this?

This repo is used to demonstrate real-time webhook events flowing into the Dev Pulse dashboard.
When you push commits, open PRs, or comment on issues here, you'll see them appear instantly
in the Dev Pulse activity feed.

## Stack

- Built on [One](https://withone.ai) for integrations
- Uses One's MCP server for AI agent execution
- Real-time webhook relay for live event streaming
